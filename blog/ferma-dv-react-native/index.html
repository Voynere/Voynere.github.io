React Native: опыт Ferma DV

16 августа 2026 · 1 мин чтения

react-native · typescript · mobile · product

Ferma DV App — React Native‑клиент фермерского e‑commerce: каталог молочки и сопутствующих товаров, корзина, оформление, зоны доставки, бонусная программа и push.

Стек на клиенте: React Native 0.81, TypeScript, React Navigation, Zustand, Firebase (Messaging + Crashlytics), Keychain, turf для проверки адреса в полигоне доставки.

Что важно по опыту:

  • тяжёлую сборку каталога (остатки, акции, картинки) держим на BFF, а не в телефоне — на устройстве тонкий page‑cache в Zustand;
  • смена зоны доставки сбрасывает кэш: иначе пользователь видит чужие остатки и цены;
  • картинки идут через OptimizedImage с URL из BFF; пер‑карточечный resolve в МойСклад — только fallback;
  • отдельные контуры: SMS/OTP‑вход, бонусы, подписка на наличие, напоминания о подарках, сборки APK/AAB/IPA.

Вывод простой: мобильный e‑commerce живёт или умирает на границе «телефон ↔ бэкенд». Если агрегировать каталог на устройстве — FPS и батарея страдают. Если отдать агрегацию BFF и оставить UI быстрым — продукт ощущается цельным.
