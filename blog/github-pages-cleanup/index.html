Как почистил voynere.github.io

15 августа 2026

На voynere.github.io лежала заглушка со скрытой ссылкой — классический SEO-мусор. Параллельно GitHub Pages падал: legacy-сборка конфликтовала с Actions workflow.

Что сделал:

  • выкинул спам и собрал нормальное портфолио на статике;
  • переключил Pages на деплой через GitHub Actions;
  • добавил `.nojekyll`, чтобы не гонять лишний Jekyll.

Для user-сайта (`username.github.io`) достаточно HTML/CSS/JS и короткого workflow: checkout → artifact → deploy-pages. Без фреймворка, без лишней сборки.
