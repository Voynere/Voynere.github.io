Колофон

Как устроен этот сайт — без CMS и без сборщика.

Стек. Статический HTML, один CSS и один JS. Шрифты — Syne и Literata. Деплой: push в main → GitHub Actions → Pages.

Контент. Заметки лежат в blog/*/index.html. Индексы, RSS, Atom и sitemap обновляю вместе с постами. Серия Ferma DV — отдельная коллекция.

Поведение. Мобильное меню, поиск и теги в блоге, прогресс чтения, оглавление по h2, копирование ссылки, горячие клавиши / и ?.

Исходники. github.com/Voynere/Voynere.github.io
